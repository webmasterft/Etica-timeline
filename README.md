# Línea de Tiempo Interactiva: Corrientes Éticas y Legalidad

Aplicación web interactiva desarrollada con HTML5, CSS moderno y Vanilla JavaScript para la visualización cronológica de corrientes éticas y su aporte con la legalidad.

## Características
- **Scroll interactivo**: animaciones de revelado con `IntersectionObserver`, barra de progreso y guía de scroll animada.
- **Selector de temas**: 4 paletas de color con persistencia (`Oro Atenas`, `Cíber Ágora`, `Esmeralda` y `Carmín`).
- **Modal analítico**: profundización en autores, obras clave y relación con el marco legal.
- **Filtro dinámico**: navegación rápida por periodos clave.

## Ejecución local
```bash
npx serve -l 9500
```
Abrir `http://localhost:9500` en el navegador.
